- Nombre: **Emprende La Virginia**

- Región: AWS `us-east-2`

## Variables de entorno

La aplicación utiliza las siguientes variables públicas:

```env
NEXT_PUBLIC_SUPABASE_URL=
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=
```

Los valores reales deben guardarse únicamente en `.env.local` durante el desarrollo y en la configuración segura del proveedor de hosting para cada entorno desplegado.

No se deben guardar en Git contraseñas, claves `secret`, claves `service_role` ni tokens de acceso personal.
